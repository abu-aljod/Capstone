# Capstone Ideas

## Some of the ideas I would like to create:

- An application that allows people to plan trips and invite people to events. 
    People who are coming to this trip, date, or event could chat through this app to stay updated. This means each user could create an account and follow other people. (This is the one that I would most likely work on. The things I need to do for this: Find an API that would help me work on it or create my own, where to save the data or which database I should use, which languages and technologies I want to write and create the application with.)

- A TODO list application. 
    The user could create a todo list, cross done work, share todo lists with multiple people for group work. This app shall also give people tips for managing their time to finish the work on time based on the type of work.

- Thoughts application.
    An application where people could type something they think of, and the app returns multiple apps and websites that would be beneficial to use based on this category. It shall give some info about those results as well. For example, features, benefits and drawbacks, whether it’s free or not, and which one would be best to use based on what they are looking for.
