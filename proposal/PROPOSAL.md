# Capstone Proposal

This project will be a website that makes planning trips and events more flexible, easier and more organized. Instead of scattered group chats and missed messages, people will have access to the dates, details, invitations and conversation for a trip all in one place. Users will be friends, families, students and community groups who organize outings together. I will build the front end with HTML, CSS, JavaScript and React, so the site is easy to use and works well on a phone as well as a computer. The focus will be on making the whole experience work well together, from the pages people see to the data behind them.

The data will mostly come from the users themselves: accounts, trips, events, invitations, the people attending, and chat messages. I will store this data and make it available to the site through an API, and I may also use outside APIs to add helpful information to a trip, such as weather, nearby places or maps. Since trip plans and account details are private, I will make sure only the people invited to a trip can see it, and that passwords and other sensitive information are kept secure. Users will be able to create an account, log in, create a trip, add events to it, invite other people, and chat with everyone attending. These features in my website will make planning trips and events easier and more organized, and create a better experience for those who are attending them. Also, as a programmer, this project will let me practice the skills that I've learned and put them together, and improve my abilities.
